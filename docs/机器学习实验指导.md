# 机器学习实验 — 苹果质量检测

## 实验目标

基于 PyTorch 和 ResNet18 构建一个 8 分类图像分类器，用于识别苹果的不同质量状态和缺陷类型。

## 数据集

8 个类别，约 170 张训练图片：

| 类别 (中文) | 类别 (英文) | 样本数 |
|-------------|-------------|--------|
| 合格 | fresh | 20 |
| 病变 | diseased | 14 |
| 碰伤 | bruised | 20 |
| 腐烂 | rotten | 20 |
| 虫伤 | insect_damaged | 20 |
| 裂果 | cracked | 16 |
| 褶皱 | wrinkled | 20 |
| 黑斑 | black_spot | 20 |

## 环境要求

已在 Ubuntu-24.04 WSL2 中配置：
- Python 3.13 + Conda
- PyTorch 2.12 (CPU)
- OpenCV, Matplotlib, scikit-learn, tqdm, TensorBoard, JupyterLab

## 实验步骤

### 1. 数据探索

```bash
cd ~/dev/student-era/projects/ml-apple-detection/notebooks

```

运行 notebook 查看：

### 2. 模型训练

```bash
cd ~/dev/student-era/projects/ml-apple-detection/src
python train.py --epochs 50 --batch-size 8 --lr 0.001
```

**关键参数说明**：
- `--epochs`: 训练轮数 (默认 50)
- `--batch-size`: 批次大小 (默认 8)
- `--lr`: 学习率 (默认 0.001)
- `--val-split`: 验证集比例 (默认 0.2)

**监控训练** (另开终端)：
```bash
tensorboard --logdir=~/dev/student-era/projects/ml-apple-detection/outputs/runs
```

### 3. 模型预测

单张图片：
```bash

```

批量预测：
```bash
python predict.py ../data/test --model ../models/best_model.pth --output ../outputs/predictions.json
```

## 模型架构

- **Backbone**: ResNet18 (ImageNet 预训练权重)
- **分类器**: 全连接层 -> 8 classes
- **输入尺寸**: 224 x 224
- **数据增强**: RandomCrop, HorizontalFlip, Rotation(15deg), ColorJitter
