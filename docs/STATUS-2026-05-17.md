## 二、已知限制与注意事项

1. **Hadoop 非自启动**：每次 WSL 重启后需手动执行 `start-dfs.sh && start-yarn.sh`。如需自动启动，可将命令加入 `/root/.bashrc`（但会拖慢 shell 启动速度）。

2. **pip 镜像仅作用于 Conda 环境**：`/opt/miniconda/etc/pip.conf` 仅对 `/opt/miniconda/bin/pip` 生效。系统默认 `pip3` 仍走官方 PyPI。

3. **Kafka KRaft 模式**：Kafka 4.x 已彻底移除 ZooKeeper 支持。当前配置为单节点 KRaft (`process.roles=broker,controller`)。如需多节点集群，需重新配置 `controller.quorum.voters`。

4. **HBase 依赖 ZooKeeper**：当前 HBase 配置指向独立 ZooKeeper (`HBASE_MANAGES_ZK=false`)。如需启动 HBase，需先启动 ZooKeeper。

5. **Hive Metastore**：当前使用内置 Derby 数据库（单用户模式）。多用户/生产环境应替换为 MySQL/PostgreSQL。

6. **student-era 非 git 仓库**：当前项目未初始化 git。如需版本控制，需手动 `git init`。
