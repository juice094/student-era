# 网络信息安全实验指导

## 实验环境

- **系统**: Kali Linux WSL2
- **用户名**: zjx
- **主机名**: kali-zjx
- **密码**: (由实验指导教师配置)

## 实验清单

| 实验编号 | 实验名称 | 核心工具 | 脚本路径 |
|----------|----------|----------|----------|
| 实验一 | 网络公开信息收集 | whois, nslookup, host, dig, nmap | `scripts/exp1-info-collection.sh` |
| 实验二 | 密码破解 | John the Ripper | `scripts/exp2-password-cracking.sh` |
| 实验三 | DoS 攻击演示 | hping3, LOIC | `scripts/exp3-dos-attack.sh` |
| 实验四 | 系统安全加固 | ss, iptables, ps, find | `scripts/exp4-system-hardening.sh` |

## 使用方法

在 Kali Linux WSL2 中执行：

```bash
cd /home/zjx/netsec-exp/scripts

# 实验一
bash exp1-info-collection.sh

# 实验二
bash exp2-password-cracking.sh

# 实验三
bash exp3-dos-attack.sh

# 实验四
bash exp4-system-hardening.sh
```
