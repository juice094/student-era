# 信息检索与搜索引擎

> 数据科学与大数据技术专业《信息检索与搜索引擎》课程实验配套资源。
> 涵盖搜索引擎使用、专利检索、文献分析与综述写作四大模块。

## 实验清单

| 实验 | 主题 | 核心内容 | 工具/平台 |
|------|------|----------|-----------|
| 实验一 | 搜索引擎使用 | 检索语法、引擎对比、网络营销应用 | 百度、搜狗、360、Bing |
| 实验二 | 专利信息检索 | IPC 分类、高级检索、法律状态分析 | 国家知识产权局、专利探索者 |
| 实验三 | 综合信息资源检索 | CNKI 高级检索、Web of Science 分析 | 中国知网、WoS |
| 实验四 | 综述写作 | 文献管理、知识图谱、思维导图、综述撰写 | NoteExpress、CiteSpace、XMind |

## 导航站

直接打开 [`index.html`](./index.html) 即可访问实验导航站，包含：
- 常用网站快捷入口（百度、知网、WoS 等）
- 每个实验的详细步骤与截图提示
- 工具下载链接（NoteExpress、CiteSpace、XMind 等）

## 实验报告要求

1. 使用学校统一的实验报告模板
2. 实验内容可打印，其余部分手写
3. 严禁雷同报告
