# 实验二：基于 SuperMap 的地图制作

## 实验目的

熟悉 SuperMap 软件基本模块，使用自带数据源进行专题图制作与数据读取，掌握缓冲区分析与叠加分析。

## 实验环境

- Windows 系统
- SuperMap iDesktop 10 软件

## 实验数据

- 全国地市级行政区划图（自带数据源，需从课程平台下载）
- 北京市全国重点文物保护单位（自带数据源）

## 实验步骤

### 1. 软件安装与启动

1. 打开文件夹 `SuperMap iDesktop 10`
2. 运行 `Setup.exe`，按安装向导完成安装
3. 安装完成后点击登录软件

### 2. 数据读取及属性查询

1. 打开**工作空间管理器** → **数据源** → **打开文件型数据源** → 选择"全国地市级行政区划图"
2. 双击"全国地市级行政区划图"，查看地图是否导入成功
3. 右键单击图层 → **浏览属性表** → **数据处理** → **SQL 查询**
   - 查询模式：查询属性信息
   - 字段信息：选择 `SmUserId`
   - 双击该字段，点击查询

### 3. 提取线数据

1. 选定"全国地市级行政区划图"
2. 菜单栏选择 **地图 → 制图 → 地图系列**（创建网格系列，自行设置参数）
3. 菜单栏选择对象进行操作：**数据 → 类型转换 → 面提取边界线**
4. 生成数据集，命名为 `ConvertResult`

### 4. 缓冲区分析

1. 工作空间管理器中选择 `ConvertResult` 数据集
2. 菜单栏选择 **分析 → 缓冲区**
3. 参数设置：
   | 参数 | 值 |
   |------|-----|
   | 数据类型 | 线缓冲 |
   | 数据源 | 全国地市级行政区划图 |
   | 数据集 | ConvertResult |
   | 缓冲单位 | 千米 |
   | 左/右半径 | 10 |
4. 生成缓冲数据集 `Buffer`

### 5. 叠加分析

1. 菜单栏选择 **分析 → 叠加分析**
2. 按提示设置参数，点击确定
3. 生成叠加层数据集 `ClipResult`

### 6. 专题图制作

1. 选择"全国地市级行政区划图"
2. 菜单栏选择 **地图 → 专题库**
3. 专题库类型中选择**等级符号专题图**
4. 生成专题图

### 7. 扩展：文物保护单位缓冲区分析

1. 数据源选择"北京市全国重点文物保护单位"
2. 缓冲区数据类型：点、面数据
3. 缓冲单位：米
4. 半径：10
5. 生成缓冲数据集 `Buffer`
6. 缓冲区分析后，进行**矢栅转化 → 栅格矢量化**处理
